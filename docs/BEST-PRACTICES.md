# Best practices and antipatterns — edition 2 (2026-10-14)

These lessons are generalized from use. They do not carry another candidate's
salary, background, legal answers, permissions or exclusions.

| Practice | Antipattern |
|---|---|
| Read the latest actual user scope and stop/resume state. | Let an old continuation or automated prompt revive stopped work. |
| Separate research, documents, data entry, submit, messages and schedules. | Treat installing a skill or connecting Gmail as blanket permission. |
| Reuse valid bounded authorization with provenance. | Ask again after every restart, or stretch it to new destinations/agreements. |
| Judge responsibilities and seniority against actual evidence. | Search only Senior PM or apply to Head based on domain keywords. |
| Keep preferred criteria and OR/equivalent alternatives intact. | Convert “preferred” into mandatory, or a range's upper number into its minimum. |
| Preserve formal reports, mentoring and influence separately. | Turn mentees into direct reports or total career into PM-specific tenure. |
| Read the complete exact current official JD. | Treat a snippet, historic body or company office directory as current role proof. |
| Require an observed source/native pairing. | Merge or replace same-title roles, UUIDs, locations or publication IDs. |
| Keep unavailable sources unresolved unless exact closure is explicit. | Call every 404, maintenance page or empty search expired. |
| Evaluate office eligibility and compensation separately from skills. | Assume good domain fit resolves location, travel, authorization or pay. |
| Preserve currency/period/base basis and geography. | Convert currencies, treat equity as cash, silently fix a typo or use an estimate as employer pay. |
| Read unknown employer receipts before another submission. | Treat zero native-ID matches or missing title-filtered emails as clearance. |
| After uncertainty, search broad employer/time-window mail and read bodies. | Reopen and resubmit because the tab disappeared or a narrow search was empty. |
| Check saved receipts and exact answers before asking again. | Ask the user to reconstruct history already in the tracker/email. |
| Scope qualification claims narrowly. | Generalize SQL, AI tools or a prototype into every production specialist requirement. |
| Ask actual required questions; leave optional references unset. | Invent references or assume permission to contact their employers. |
| Present the exact current agreement's meaning. | Ask consent to a different background-check statement than the live disclaimer. |
| Respect candidate-authored/no-AI conditions. | Polish AI prose and represent it as an unassisted response. |
| Verify email, settled fields, choices and files after parsing. | Trust stale autofill or typed text that never registered as a dropdown option. |
| Inspect every rendered artifact page and actual hyperlinks. | Upload a correct-looking filename with stale contents, clipping or wrong links. |
| Keep approved files/version hashes and exact role folders. | Recreate completed covers or silently substitute an exploratory résumé. |
| Wait for settled exact success and save it immediately. | Count clicks, “saving”, closed tabs or no error as submitted. |
| Preserve actor, time and evidence strength. | Count historical reconciliation as new applications or legacy labels as employer proof. |
| Save checkpoints and close completed/auth-gated tabs. | Accumulate dozens of tabs or lose unsaved work by closing without a checkpoint. |
| Check partial writes before retrying. | Replay a successful update because a later assertion failed. |
| Use one browser controller and one canonical writer. | Have parallel workers fight over pickers or independently regenerate shared tables. |
| Continue independent eligible work when one role is held. | Wait on a missing answer for every role, or fill a batch with adjacent padding. |
| Report coverage and concrete holds. | Declare completion because no role is immediately ready or a count target was hit. |
| Dedupe confirmed calendar appointments before changes. | Invent time/duration or send recruiter invitations during a private calendar update. |
| Separate interviews requested, scheduled and completed. | Infer attendance from an invite or the passage of time. |
| Describe patterns in a defined observed cohort. | Treat no response as rejection or small samples as causal hiring evidence. |

When a tool review rejects an action, retain its exact reason and communicate
the remaining block. A safer correction may be retried through normal review
when justified; a new worker/tool is not a bypass. Process complexity should be
proportional to the risk: a solo candidate does not need a hierarchy, hash audit
or fresh screenshot for every harmless edit. Evidence of the actual material
state matters more than ceremonial checklists.
