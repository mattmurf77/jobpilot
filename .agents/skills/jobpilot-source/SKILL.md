# Source and qualify jobs

Read [source, qualification and dedupe procedures](../../../docs/WORKFLOW.md)
and [the table schema](../../../docs/DATA-MODEL.md). Load fresh private profile,
experience, permissions, leads and applications including unresolved receipts.
If no profile exists, use `jobpilot-start`; useful setup need not wait for every
optional preference. Research permission does not authorize application entry.

Search the user's appropriate title family, not only one title. For PM include
Senior/Lead/Staff/Principal/Technical and qualifying Product Owner/leadership
roles according to demonstrated scope. Assess full duties; do not pad with
program, operations, analyst or consulting roles without an exact exception.

Use supported public research or authenticated pages actually accessible;
LinkedIn/Indeed are discovery sources, then verify the employer-direct role.
Save source URLs/full IDs, discovery date/basis, official JD, location, original
salary text/basis and evidence. Read one listing at a time, pace normally and
honor stricter user/service limits; no rapid retry loops or bypasses.

Before cover drafting/data entry, save exact-role selection evidence for:
current official native identity and acceptance, actual primary duties,
mandatory requirement alternatives and preferred criteria, supported experience,
employer restrictions, actual office/remote jurisdiction/cadence/travel,
currency/period/base compensation and fresh duplicate/unresolved-receipt review.
Keep historic sources; title similarity or a snippet is not a native pairing.
404/maintenance/empty search is a recovery hold, not exact expiry. No unsaved
substitutes during a bounded saved-backlog task.

Rank supported matches by responsibility fit and the user's location/pay
priorities, then readiness. Record a concrete reason, next action and evidence
for holds; preserve `null` disposition until final evidence supports expired,
applied or not a fit. Null does not imply eligible/open. Report source rows,
distinct roles and ready candidates separately, without arbitrary batch padding
or a false completion claim. Return concise missing questions to the user and
continue independent authorized research. Do not submit, message or schedule
from a sourcing-only request.
